# Security policy

## Reporting a vulnerability in AnhourCam TV
Please **don't open a public issue.** Use GitHub's
[private vulnerability reporting](https://github.com/anhourtec/AnhourCam-TV/security/advisories/new).
We aim to reply within 7 days.

In scope: the AnhourCam TV app, the LAN pairing server (phone sign-in and phone layout editor), and
scripts in this repository.

## Not in scope
Vulnerabilities in BitVision's own cloud, apps or devices. Report those to BitVision. Do not
test BitVision's servers on behalf of this project.

Threat model and pairing-server controls: [docs/security.md](docs/security.md).
