traffic. Raw captures → `captures/` (git-ignored). Redacted extracts → `samples/`.

## Method
- XHR/Fetch: `browser_network_requests` + `browser_network_request` for bodies.
- WebSockets: an **init script** (`context.addInitScript`) wrapping `window.WebSocket`, storing
  per-socket frames (direction, size, text ≤600 chars, first 64 bytes hex) in `window.__cgws`;
  dumped with `browser_evaluate` to `captures/`. (`page.on('websocket')` state does not persist
  between Playwright MCP calls.)
- Redacted samples are generated by script, then `scripts/check-redaction` must pass.
- JS: download portal bundles to `captures/js/` to locate signing / decoder logic.
