# 2026-10-30 — Second test device: Xiaomi Mi Box 4K

## Done
- Found the Mi Box on the network: it shared `<IP_1>` with an IP camera (ARP: camera MAC
  prefix); the maintainer gave it a free static address. Network ADB on 5555 after USB debugging.
- `MIBOX4`, Android 9 (API 28), Amlogic `gxl`, 2 GB, hardware HEVC/AVC decoders (9 declared each).
- Crash when the phone opened the pairing page: `ByteArrayOutputStream.toString(Charset)` is API 33.
  Wrote `scripts/check-android-api.py` (javap + SDK `api-versions.xml`), found 13 calls newer than
  minSdk 25 in `:pairing` / `:ipcam` (API 33 and 26), replaced them all, and added the check to
  `./gradlew check`.
- "Use IP cameras only" was clipped on 960×540 dp screens: moved to the phone column.
- Dashboard: each IP camera row has a Remove button with a confirmation page; removing a camera
  clears it from every layout on the TV.
- Maintainer signed in to BitVision on the Mi Box from a phone; tiles play on hardware decoders.
