# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and constructive. Harassment, personal attacks and sharing others' private data
(including camera footage) are not tolerated. Report problems to the maintainers through a
private GitHub security advisory or by contacting [anhourtec](https://github.com/anhourtec).
